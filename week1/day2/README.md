# Day 2 - Salesforce Platform Basics

## 1. What is Salesforce Platform?

Salesforce Platform is a cloud-based platform that helps businesses build, customize, and manage applications. It provides tools to store data, automate processes, create reports, and develop applications with little or no coding.

## 2. Key Concepts

### App

An App in Salesforce is a collection of tabs, objects, and features designed to support a specific business process. Examples include Sales App and Dreamhouse App.

### Object

An Object is a database table used to store information. Objects contain records and fields.

Examples:

* Account
* Contact
* Opportunity
* Property (Custom Object)

### Tab

A Tab provides access to objects, records, dashboards, reports, and other Salesforce features. Tabs help users navigate through the application easily.

## 3. Difference Between Configuration and Coding

| Configuration (No-Code / Low-Code)              | Coding (Programmatic Development)           |
| ----------------------------------------------- | ------------------------------------------- |
| Uses clicks instead of code                     | Requires programming                        |
| Faster to implement                             | More flexible and powerful                  |
| Uses tools like Flow Builder and Object Manager | Uses Apex and Lightning Web Components      |
| Suitable for most business customizations       | Suitable for advanced business requirements |
